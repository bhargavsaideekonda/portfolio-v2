# Bhargav Sai Deekonda — Portfolio

Personal portfolio built with Vite, React, React Three Fiber, GSAP and Framer Motion.

## Edit the content

All text, links and projects are in `src/data.js`.

## Run locally

```
npm install
npm run dev
```

## Publish

Every push to `main` builds the site and deploys it to GitHub Pages
(see `.github/workflows/deploy.yml`).
